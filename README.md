Projeto desenvolvido durante meus estudos de Python para praticar lógica de programação.

## Funcionalidades

- Adicionar produtos
- Remover produtos
- Visualizar produtos
- Calcular o total da compra

## Tecnologias

- Python

### 2. Clone o repositório

```bash
